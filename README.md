# 🏋️ AI Real-time GYM Coach

> Real-time AI-powered workout tracking and form coaching using computer vision and voice feedback.

## 🚀 Live Demo

https://ai-gym-coach-vision.streamlit.app/

## ✨ Features

- 🎥 Real-time webcam workout analysis
- 🧍 MediaPipe pose detection
- 🔢 Automatic repetition counting
- 📊 Set and workout progress tracking
- 🏋️ Multiple exercise detection
- 📐 Real-time joint-angle metrics
- 🤖 AI-powered coaching feedback
- 🔊 Voice coaching
- 📜 Workout history
- 🔐 User login
- 💾 SQLite workout data storage
- ☁️ Streamlit Cloud deployment

## 🏋️ Supported Exercises

- Squats
- Push-ups
- Biceps Curls (Dumbbell)
- Shoulder Press
- Lunges
